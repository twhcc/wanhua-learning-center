## 預覽

## 免費上線
可整個資料夾上傳 GitHub Pages。因本版照片已轉成 WebP 並縮圖，容量比原始 438MB ZIP 小很多。

## 關於影片
原始 ZIP 有大型 MP4。免費網站正式版建議：
- 影片放 Google Drive / YouTube（可設定不公開）
- 網站只嵌入播放器
這樣不用把幾十 MB 的影片直接塞進 GitHub。
